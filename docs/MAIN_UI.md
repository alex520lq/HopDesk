# HopDesk 主窗口 UI 规范

## 目标

HopDesk 使用一个常驻后台进程和一个可重复打开的主窗口。Windows 使用 Win32 原生控件，macOS 使用 Cocoa 原生控件；不引入 Electron、Qt 或 WebView。

两端必须保持相同的：
- 六个页面及顺序：概览、连接、设置、传输、日志、更新。
- 页面标题、字段名称、按钮文案、状态语义和操作结果。
- 左侧导航、顶部页面标题/连接状态、底部版本/状态信息的布局层级。
- 设置字段、校验范围、保存语义和重启提示。

系统窗口边框、字体渲染、按钮外观和系统菜单由各自原生平台负责，不要求像素级复制系统控件。

## 视觉方向

- 现代、克制、专业的桌面工具，不使用游戏化装饰或大面积渐变。
- Windows 使用明确的浅色画布、低对比卡片和蓝色活动导航；macOS 使用系统语义色。保留原生焦点/键盘行为。
- 固定左侧导航，右侧内容以清晰分组卡片组织。
- 统一采用约 8 pt 的间距节奏；卡片圆角适中，边框低对比。
- 连接状态在顶部和概览页重复展示；颜色只是辅助，文字必须明确表达状态。
- 主窗口建议尺寸约 1140 × 800；最小尺寸应保证设置页和传输页不被裁切。
- 关闭主窗口只隐藏窗口，后台键鼠、剪贴板和网络服务继续运行。

## 页面结构

### 1. 概览

显示连接状态、本机角色、对端信息、控制/数据通道状态，以及常用显示器操作。

按钮：
- 切换到 Mac 显示
- 切回 Windows 显示
- 唤醒显示
- 显示睡眠
- 打开传输管理

键鼠共享仍由既有鼠标边缘移交逻辑控制；页面展示状态，不伪造跨平台不支持的手动切换入口。

### 2. 连接

显示本机角色、当前连接状态、对端地址/设备信息和控制/数据端口。

“重新连接”会让当前控制会话断开并进入既有自动重连流程；不改变协议或认证方式。

### 3. 设置

统一编辑现有 `hopdesk.conf` 配置项：
- 设备名称、服务端地址、控制端口、数据端口、共享 Token。
- 服务端/客户端边缘、触发延迟、切换冷却、边缘内缩。
- Windows/Mac 显示器输入源、唤醒时长。
- 传输分块大小、Mac 切源/睡眠命令。

Token 使用安全输入控件且必填，两端必须设置相同的非空值。两端都提供角色下拉框；仅客户端启用服务端地址输入。服务器在连接页展示本机活动 IPv4 地址。

设置与运行配置分离；恢复默认值不会改变当前连接。保存与日志尾部读取在后台执行，结果回到 UI 线程。

保存使用共享核心的 `hop_config_save_atomic`：同目录临时文件、完整写入/flush、原子替换。保存失败时保留旧配置。网络监听、认证和连接参数在重启 HopDesk 后完整生效；UI 必须明确提示，不能假装已热应用。

### 4. 传输

在主窗口内显示当前任务、文件明细、进度、传输历史。

操作：
- 取消传输。
- 重试选中的失败发送文件。
- 展开/折叠目录（平台控件允许的情况下，对当前选中的目录操作）。

刷新必须使用传输状态快照 API；不得在 UI 线程执行文件扫描、读写或网络传输。

### 5. 日志

显示当前日志文件的最近内容，并提供刷新/复制操作。日志查看不得阻塞网络、键鼠和剪贴板工作线程；日志不存在时显示明确空状态。

### 6. 更新

显示当前版本和更新源，提供“检查更新”入口。沿用既有清单校验、SHA-256、独立安装器、更新准入和回滚流程。更新源不可用时必须显示检查失败，不能误报为“已是最新版本”。

## 托盘/菜单栏行为

两端托盘/菜单栏菜单严格只保留：
1. 打开
2. 退出

Windows 左键单击托盘图标直接打开主窗口，右键显示上述菜单。macOS 菜单栏图标显示相同的“打开/退出”菜单。

“打开”始终复用同一个主窗口实例并置前；不能创建多个主窗口。关闭主窗口只隐藏，不退出进程。只有“退出”才停止后台服务并结束进程。

## 实现边界与验收

- UI 线程只做控件更新和轻量快照读取；网络、目录枚举、文件读写和更新下载继续在现有后台工作流中执行。
- 配置保存、更新、取消/重试等操作必须有明确成功/失败反馈。
- 连接状态、传输状态和日志空状态不能只依赖颜色。
- Windows 和 macOS 都必须通过原生构建与核心回归测试。
- 实机验收：反复打开/关闭主窗口 20 次；连接/断线重连；保存配置并重启核对；发送/接收文件和图片；取消/重试；刷新/复制日志；检查更新成功/失败提示。
- UI 构建通过不等同于真实双机端到端验收；实机结果单独记录。

## 本轮双角色验收（待原生设备执行）

- Windows 服务器 → macOS 客户端、macOS 服务器 → Windows 客户端分别执行完整流程。
- 六页往返切换、最小高度、最大化、100% / 125% / 150% / 200% 缩放及跨 DPI 显示器：不得出现旧页面透出或控件重叠。
- 设置保存失败、非法数字、角色切换、恢复默认、关闭重开：当前会话不被草稿修改，重启后读取已保存配置。
- 四个边缘移交/收回，Cmd/Ctrl、Shift、Alt、拖拽、滚轮；断线、队列溢出与 Ctrl+Alt+Esc 后不遗留按下状态。
- 双向 Unicode 文本、图片、空文件/目录、大文件并发；取消、重试、CRC、断线重连与历史记录。
- 自动化编译/协议测试不替代上述原生视觉与双机验收；没有设备证据不得标为已通过。
