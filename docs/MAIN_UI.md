# HopDesk 主窗口 UI 规范（统一 CUI）

## 架构与边界

macOS 与 Windows 主窗口共用一套 CUI 1.5.0 页面、组件、布局和交互实现：

- 公共页面与状态：src/ui/hopdesk_ui.c、src/ui/hopdesk_ui.h。
- macOS 适配：src/mac/main_ui.m，负责 Cocoa 窗口生命周期、权限、显示器、音频、配置和日志。
- Windows 适配：src/win/main_ui.c，负责 Win32 窗口生命周期、显示器、音频、配置和日志。
- 托盘/菜单栏、权限、键鼠注入、网络、剪贴板、文件传输与音频引擎继续由各平台原生实现。

CUI 固定为 Git submodule，版本为 v1.5.0。macOS 优先使用 Metal，Windows 优先使用 Direct3D 12；两端保留 OpenGL 与软件渲染回退。

## 窗口生命周期与内存

打开主窗口时创建 CUI app、renderer、字体图集和页面状态；关闭主窗口时销毁 CUI app/context，释放 UI 快照与 renderer。托盘/菜单栏和后台服务继续运行，重新打开时重新创建主窗口。

系统 CJK 字体通过只读内存映射提供给 CUI，不复制整个字体文件到应用堆内存；窗口关闭、CUI context 销毁后解除映射。CUI 默认字体和图标字体由固定版本的 CUI 提供。

UI 快照采用 revision 驱动：
- 最多缓存 32 条活动任务和 24 条历史记录。
- 文件明细每页 24 条，使用现有文件跟踪分页接口。
- 任务和历史快照只在 revision 变化时重新读取。
- 窗口打开期间最多每 500 ms 唤醒一次，用于刷新进度；其他 UI 更新由平台事件触发。

## 页面结构

一级导航顺序固定为：**概览、设备、传输、设置**。

### 概览

连接状态仪表盘展示控制通道、文件数据通道、键鼠控制权和声音通道。页面展示本机与对端信息、连接状态、重新连接入口，以及显示器输入源/唤醒操作。macOS 会展示键鼠权限状态；Windows 不需要 macOS 式辅助功能授权。

### 设备

展示本机名称、角色、地址、屏幕尺寸、对端地址和控制/数据端口。服务器/客户端角色是独立配置，不把操作系统平台等同于网络角色。声音发送和播放是独立能力，不随角色反转。

### 传输

传输页展示发送与接收总体进度、最多 32 条活动任务、按 24 条一页读取的文件明细，以及最近 24 条历史记录。任务选择使用稳定 Task ID；文件明细使用现有分页和 revision 接口，不一次性复制完整的 8192 项明细。

取消操作先显示二次确认，再按选中 Task ID 发出；确认区将「保留任务」放在「确认取消」之前，键盘焦点顺序优先保留任务。只有失败的发送文件可重试。网络 I/O、目录扫描和文件读写仍在后台线程执行。

### 设置

设置页面统一分组：

- **设备与连接**：设备名称、角色、服务器地址、控制端口、数据端口和共享 Token。
- **声音通道**：发送本机声音、播放对端声音，两个开关互相独立。
- **键鼠与显示器**：服务端/客户端边缘、延迟、冷却、边缘内缩、显示器输入源、唤醒时长和 Mac 命令。
- **文件传输**：分块大小和速率上限。
- **保存与辅助**：保存、恢复默认、检查更新、键鼠权限入口和运行日志刷新/复制。

Token 必填且两端一致。客户端必须填写服务器地址。保存先验证完整配置并原子写入；声音能力尝试即时应用，角色、网络、地址和认证参数重启后生效。保存期间锁定设置编辑，失败保留草稿并允许重试。

## 托盘/菜单栏

托盘/菜单栏图标仍由原生平台代码维护，并继续承担连接和传输状态摘要。左键单击打开主窗口，右键菜单保留打开/退出。关闭主窗口不停止后台键鼠、剪贴板、网络和传输服务；只有退出操作才结束应用。

## 构建与验收

初始化依赖：

```sh
git submodule update --init --recursive
```

构建：

```sh
sh scripts/build-mac.sh
pwsh scripts/build-win.ps1 -Compiler msvc
```

双平台 CI 必须通过；真实设备仍需验收托盘打开/关闭/重开、四个页面、DPI/窗口尺寸、配置保存、权限、音频、显示器切换、双向传输、取消/重试和长时间运行。CI 构建通过不等同于实机视觉和双机端到端验收。
